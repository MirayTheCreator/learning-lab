# Контекст: «Тренажёр технических терминов»

## Зачем
Автор учится работать с ИИ-агентом и осваивает технические термины. Нужен простой тренажёр с карточками, чтобы повторять термины и видеть свой прогресс.

## Кто автор
Не программист. Код пишет ИИ-агент, а решения по продукту принимает автор.

## Требования (подтверждены автором)
- **Пользователь:** только автор. Регистрации, аккаунтов и общего доступа нет.
- **Устройство:** одно. Синхронизация между устройствами не нужна.
- **Прогресс:** хранится в браузере на этом устройстве.
- **Термины:** стартовый набор составляет ИИ-агент, а автор потом правит и дополняет его.
- **Модули стартового набора:**
  1. Работа с ИИ-агентами
  2. Git и GitHub
  3. Веб и приложения
  4. Терминал и файлы
- **Карточка:**
  - на лицевой стороне термин (и английский оригинал, если он есть);
  - на обороте простое объяснение и жизненный пример.
- **Отметки:** «знаю» / «повторить».
- **Повторение:** интервальное. Даже знакомые термины возвращаются через увеличивающиеся промежутки времени, как в Anki.
- **Прогресс:** виден по каждому модулю.
- **Публикация:** бесплатная; выбирается самое простое решение.

## Не нужно
- Аккаунты, вход, сервер.
- Синхронизация между устройствами.
- Совместное использование с другими людьми.
