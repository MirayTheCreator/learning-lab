# Видение: «Тренажёр технических терминов», версия 1

Основано на [context.md](context.md). Главный принцип — самое простое решение, которое работает и бесплатно публикуется.

---

## 1. Что входит в первую версию

### Экраны

**Главный экран**
- Список из 4 модулей.
- У каждого модуля прогресс: сколько терминов выучено и сколько ждёт повторения сегодня.
- Кнопка «Заниматься».

**Экран занятия**
1. Показывается карточка с термином.
2. Ты вспоминаешь значение и нажимаешь «Показать ответ».
3. Видишь объяснение и пример.
4. Нажимаешь «Знаю» или «Повторить».
5. Появляется следующая карточка.

**Конец занятия**
- Короткий итог: сколько терминов пройдено и сколько отмечено «знаю».

**Сброс прогресса**
- Кнопка, чтобы начать модуль заново. Перед сбросом приложение просит подтверждение.

### Содержание
- Примерно по 15 терминов в каждом модуле, всего около 60.
- Набор можно расширить позже.

### Как работают интервальные повторения: «коробочки»
Самая простая схема интервальных повторений называется системой Лейтнера. Представь 5 коробочек:

| Коробочка | Когда термин покажется снова |
|---|---|
| 1 | в этот же день |
| 2 | через 1 день |
| 3 | через 3 дня |
| 4 | через 7 дней |
| 5 | через 30 дней |

- **«Знаю»** — термин переходит в следующую коробочку и вернётся позже.
- **«Повторить»** — термин возвращается в коробочку 1.
- **Выученный термин** — тот, который лежит в коробочке 5.

**Почему так:** схема даёт главный эффект интервальных повторений и при этом легко объясняется и проверяется. Сложные формулы, как в Anki, для 60 терминов не нужны.

### Что НЕ входит в первую версию

| Функция | Почему её нет |
|---|---|
| Добавление и редактирование терминов в приложении | Термины лежат в одном понятном файле. Его правит ИИ-агент по твоей просьбе, и это проще, чем делать отдельную форму. |
| Аккаунты, синхронизация, несколько устройств | Ты занимаешься один и на одном устройстве. |
| Обратный режим (по объяснению вспомнить термин) | Можно добавить потом, если захочется. |
| Резервная копия прогресса в файл | См. риски ниже. Это первый кандидат на вторую версию. |

## 2. Стек: на чём сделано

**Обычные HTML, CSS и JavaScript, без фреймворков и без сборки.**

Простыми словами:
- **HTML** — что есть на странице (кнопки, текст).
- **CSS** — как это выглядит (цвета, размеры).
- **JavaScript** — как это работает (переворот карточки, подсчёт прогресса).

Это три базовых языка, которые понимает любой браузер. Ничего устанавливать не нужно.

**Почему не React, Vue и подобные фреймворки.** Они нужны большим приложениям. Им требуются установка инструментов, «сборка» и обновления. Для тренажёра из нескольких экранов это лишняя сложность, которую тебе пришлось бы обслуживать.

**Плюс для обучения.** Приложение можно открыть двойным щелчком по файлу на компьютере, и оно сразу заработает. Никаких серверов и команд запуска.

### Файлы проекта (примерно 4 файла)

| Файл | Что в нём |
|---|---|
| `index.html` | страница приложения |
| `style.css` | оформление |
| `app.js` | логика: карточки, коробочки, прогресс |
| `terms.js` | все термины по модулям; этот файл ты будешь чаще всего просить дополнить |

## 3. Где хранить данные

Данных два вида, и они хранятся по-разному.

### Термины — в файле `terms.js` внутри репозитория
- Термины одинаковые всегда и меняются только тогда, когда ты решишь их поменять.
- Им место в коде, рядом с приложением.
- Git помнит историю правок, поэтому любое изменение можно откатить.

### Прогресс — в браузере (localStorage)
**localStorage** — это небольшое хранилище, которое браузер выделяет каждому сайту. Приложение записывает туда, в какой коробочке лежит каждый термин и когда его показать снова.

Почему так:
- **Не нужны сервер, база данных и вход** — ты занимаешься один и на одном устройстве.
- **Бесплатно и мгновенно.** Данные никуда не отправляются по интернету.
- **Приватно.** Твой прогресс видишь только ты.

## 4. Публикация: GitHub Pages

**GitHub Pages** — бесплатный хостинг от GitHub. Он берёт файлы из репозитория и показывает их как сайт по адресу:

https://miraythecreator.github.io/learning-lab/

Почему он:
- **Репозиторий уже на GitHub** — не нужен ещё один сервис и ещё один аккаунт.
- **Бесплатно** для публичных репозиториев.
- **Подходит для простого HTML, CSS и JavaScript** — именно такой стек мы выбрали.
- **Обновление простое:** отправил изменения на GitHub (push) — через минуту сайт обновился.

> Публикация и любой push на GitHub делаются только после твоего явного «да».

## 5. Риски и ограничения (честно)

**Прогресс живёт только в этом браузере.**
Он пропадёт, если:
- очистить данные браузера (историю, cookies);
- открыть приложение в другом браузере;
- открыть его в режиме «инкогнито».

На iPhone, в Safari, есть ещё одна особенность: если долго не заходить на сайт (около недели), браузер может стереть его данные сам.

Если это станет проблемой, во второй версии можно добавить кнопки «Скачать резервную копию» и «Загрузить из файла».

**Репозиторий публичный.** Термины и код увидит любой, кто зайдёт на GitHub. Прогресс туда не попадает, он остаётся только в браузере.
